# 模型加框架

AI Agent 可以理解为“模型 + 框架”的组合。模型提供推理、语言理解和代码生成能力；框架提供文件、浏览器、数据、脚本、工具调用和任务编排能力。

## 模型负责什么

- 理解论文问题和方法。
- 解释数据和分析结果。
- 判断下一步分析方向。
- 生成代码、报告和图表说明。

## 框架负责什么

- 管理文件和材料。
- 调用浏览器、搜索、下载、脚本运行等工具。
- 保存中间结果。
- 把多步任务串成流程。

## 配合方式

强模型没有工具框架，容易停在“会说”。有框架但模型能力不足，又容易把任务做偏。可靠的 Agent 工作流需要两者同时成立，并且由人把控目标、边界和验收标准。
