# 对话框与 AI Agent

传统对话框适合快速问答、摘要、解释和初步推理。AI Agent 则更适合把复杂目标拆成多步行动，并在行动中更新理解。

## 对话框更擅长

- 快速概括论文主旨。
- 解释术语、方法和背景。
- 把英文论文转成易读的中文说明。
- 生成单次回答或一次性图示。

## AI Agent 更擅长

- 查找相关论文、数据、代码和补充材料。
- 把公开数据转化为可分析对象。
- 写脚本并运行，处理失败和依赖问题。
- 生成静态图、动态图、报告、表格和后续任务建议。
- 在工具执行结果基础上重新解释论文。

## 核心区别

对话框主要是在“说”，Agent 可以从“说”推进到“做”。这不是量的提升，而是任务形态的变化：从回答问题变成管理一个小型研究流程。
