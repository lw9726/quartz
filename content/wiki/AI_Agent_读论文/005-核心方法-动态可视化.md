# 动态可视化

动态可视化适合表达随时间发生的结构变化。对于空间轨迹、群体分裂、活动范围变化这类问题，静态图能展示结果，动态图更容易展示过程。

## 适用场景

- 年度变化明显的数据。
- 空间分布和重叠度随时间演化。
- 需要向非专业读者解释过程性变化。
- 论文原图偏静态，但公开数据允许重新组织叙事。

## Agent 的作用

Agent 可以把数据清洗、逐年分帧、脚本生成、图像导出、GIF 或视频合成串起来。更重要的是，它可以把中间产物保留下来，让读者知道动态图不是凭空生成的，而是由一组可检查的步骤组成。

## 判断标准

好的可视化不是更炫，而是让问题更可解释。动态图应该帮助看清变化机制，而不是用动效掩盖数据含义。
