# Agent 论文阅读工作流

一个有效的 Agent 论文阅读流程，可以从“读懂论文”逐步推进到“复现关键材料”和“生成新的理解资产”。

## 流程

1. 获取论文主线：让 Agent 提取研究问题、背景、方法、数据、核心结论和局限。
2. 追问方法细节：拆解数据采集、统计分析、网络分析、空间分析等方法层。
3. 定位开放材料：查找补充材料、数据集、代码仓库、DOI 和机构新闻稿。
4. 运行最小复现：先跑一段小脚本验证数据结构和基础图表。
5. 深化分析目标：要求 Agent 生成更能说明问题的图表或对照表。
6. 记录执行过程：保留脚本、错误、修复方案和结果解释。
7. 转化为知识节点：把论文中的概念、方法、案例、工具和洞察拆入知识库。

## 关键点

Agent 的优势来自闭环：阅读给出假设，工具执行验证假设，结果反过来修正理解。
