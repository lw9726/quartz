# AI Agent 的动手能力

AI Agent 的关键差异不在于“更会回答”，而在于它能把一个理解任务转化为一组可执行步骤。对论文阅读来说，这意味着它不只解释论文结论，还可以围绕论文展开检索、数据整理、代码运行、图表生成和结果复核。

## 含义

“动手能力”包括三层：

- 能主动使用外部资料，而不是只依赖当前对话上下文。
- 能生成并执行分析步骤，例如下载数据、运行脚本、生成图表。
- 能把执行结果纳入下一轮解释，使解释建立在实际操作反馈之上。

## 价值

这使论文阅读从“文本理解”进入“过程复现”。当 Agent 真的跑过数据、处理过异常、生成过可视化，它对方法和结果的说明会更接近研究过程本身，而不是停留在摘要层面。
