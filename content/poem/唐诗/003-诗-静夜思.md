# 003-诗-静夜思

**作者:** [[poem/诗人/001-诗人-李白]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 五言绝句  
**常见场景:** 小学常见

**原文:**
```
床前明月光，疑是地上霜。
举头望明月，低头思故乡。
```

**核心概述:** 这首诗以月光触发乡愁，用极简语言写出漂泊者普遍的思乡经验。

**主要意象:**
- 月光：连接眼前异乡与记忆中的故乡
- 霜：把清冷夜色转化为可感的孤独
- 举头与低头：用动作完成从观看到怀乡的转折

**学习要点:**
- 注意诗中没有直接说“愁”，而是通过动作和景物呈现情绪
- 适合入门理解古诗的意象和留白
- 可与[[poem/唐诗/018-诗-九月九日忆山东兄弟]]比较思乡主题
