# 008-诗-绝句·两个黄鹂鸣翠柳

**作者:** [[诗人/002-诗人-杜甫]]  
**朝代:** [[时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学常见

**原文:**
```
两个黄鹂鸣翠柳，一行白鹭上青天。
窗含西岭千秋雪，门泊东吴万里船。
```

**核心概述:** 这首诗像一幅明丽工整的春景画，用颜色、空间和动静对比表现安定生活的欣喜。

**主要意象:**
- 黄鹂、翠柳、白鹭、青天：色彩鲜明，构成春景画面
- 窗与门：把远景收进日常居所
- 千秋雪与万里船：扩展时间和空间尺度

**学习要点:**
- 注意对仗和色彩搭配
- 理解“窗含”“门泊”的空间组织
- 可与[[诗人/002-诗人-杜甫]]的沉郁作品形成对照
