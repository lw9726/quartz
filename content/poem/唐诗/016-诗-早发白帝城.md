# 016-诗-早发白帝城

**作者:** [[poem/诗人/001-诗人-李白]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学常见

**原文:**
```
朝辞白帝彩云间，千里江陵一日还。
两岸猿声啼不住，轻舟已过万重山。
```

**核心概述:** 这首诗写舟行迅疾和心情轻快，常被理解为李白遇赦后重获自由的快意之作。

**主要意象:**
- 彩云白帝：开篇明丽高远
- 猿声两岸：让峡江旅程有声音和速度
- 轻舟万重山：表现阻隔已过、身心轻快

**学习要点:**
- 重点体会“轻舟已过万重山”的速度感和解脱感
- 诗中景物明快，和李白豪放气质相合
- 可与[[poem/唐诗/006-诗-望庐山瀑布]]比较李白写景的动势
