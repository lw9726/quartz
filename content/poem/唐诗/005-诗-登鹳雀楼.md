# 005-诗-登鹳雀楼

**作者:** [[poem/诗人/025-诗人-王之涣]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 五言绝句  
**常见场景:** 小学常见

**原文:**
```
白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。
```

**核心概述:** 这首诗由登楼所见推出人生启示，把视野、进取和境界提升联系在一起。

**主要意象:**
- 白日与群山：开阔辽远的空间
- 黄河入海：时间与气势的流动
- 上一层楼：象征继续进取

**学习要点:**
- 前两句写景，后两句议理，结构非常清楚
- 重点理解“更上一层楼”的比喻意义
- 可与[[poem/唐诗/010-诗-望岳]]比较登高主题
