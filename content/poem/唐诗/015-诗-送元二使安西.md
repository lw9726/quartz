# 015-诗-送元二使安西

**作者:** [[诗人/017-诗人-王维]]  
**朝代:** [[时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学至初中常见

**原文:**
```
渭城朝雨浥轻尘，客舍青青柳色新。
劝君更尽一杯酒，西出阳关无故人。
```

**核心概述:** 这首送别诗以清晨雨色和一杯酒写深情，含蓄地表现远行后的孤独。

**主要意象:**
- 朝雨轻尘：营造清新又略带离情的环境
- 青青柳色：承接古代折柳送别传统
- 阳关：象征边地远行和故人难再

**学习要点:**
- 理解“更尽一杯酒”背后的惜别与牵挂
- 注意景物清新而情感深沉的反差
- 可与[[唐诗/007-诗-赠汪伦]]比较送别诗的不同语气
