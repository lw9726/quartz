# 012-诗-枫桥夜泊

**作者:** [[诗人/026-诗人-张继]]  
**朝代:** [[时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学至初中常见

**原文:**
```
月落乌啼霜满天，江枫渔火对愁眠。
姑苏城外寒山寺，夜半钟声到客船。
```

**核心概述:** 这首诗用夜色、钟声和客船写旅途愁绪，是以声音完成情绪收束的名篇。

**主要意象:**
- 月落、乌啼、霜天：构成清冷夜景
- 江枫、渔火：让孤旅愁绪有了可见背景
- 夜半钟声：把远处寺院与客船联系起来

**学习要点:**
- 注意“钟声”在结尾制造的空间感和余韵
- 理解旅愁不是直说，而是由景物共同托出
- 适合和[[唐诗/003-诗-静夜思]]比较夜景与思乡
