# 009-诗-春夜喜雨

**作者:** [[poem/诗人/002-诗人-杜甫]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 五言律诗  
**常见场景:** 小学至初中常见

**原文:**
```
好雨知时节，当春乃发生。
随风潜入夜，润物细无声。
野径云俱黑，江船火独明。
晓看红湿处，花重锦官城。
```

**核心概述:** 这首诗写一场及时春雨，体现杜甫对自然、农事和民生的温厚关注。

**主要意象:**
- 好雨：带有拟人色彩，像懂得时节的朋友
- 潜入夜、细无声：突出春雨的轻柔滋润
- 锦官城花重：写雨后繁盛景象

**学习要点:**
- 理解“喜”不直接喊出，而由春雨的及时和滋润体现
- 注意颔联“随风潜入夜，润物细无声”的经典表达
- 可与[[poem/唐诗/004-诗-春晓]]比较春雨后的感受
