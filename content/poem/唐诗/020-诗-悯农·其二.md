# 020-诗-悯农·其二

**作者:** [[poem/诗人/028-诗人-李绅]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 五言绝句  
**常见场景:** 小学常见

**原文:**
```
锄禾日当午，汗滴禾下土。
谁知盘中餐，粒粒皆辛苦。
```

**核心概述:** 这首诗用农人劳作场景提醒读者珍惜粮食，语言直白而有道德力量。

**主要意象:**
- 烈日锄禾：突出劳动艰辛
- 汗滴禾下土：把辛苦转为可见画面
- 盘中餐：把田间劳动和日常饮食连接起来

**学习要点:**
- 理解诗的教育意义来自具体劳动场景
- 注意“谁知”带出的反问力量
- 适合与民生、劳动主题关联
