# 002-诗-行路难

**作者:** [[poem/诗人/001-诗人-李白]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 乐府诗  
**常见场景:** 初高中常见

**原文:**
```
金樽清酒斗十千，玉盘珍羞直万钱。
停杯投箸不能食，拔剑四顾心茫然。
欲渡黄河冰塞川，将登太行雪满山。
闲来垂钓碧溪上，忽复乘舟梦日边。
行路难，行路难，多歧路，今安在？
长风破浪会有时，直挂云帆济沧海。
```

**核心概述:** 这首诗写仕途受阻后的苦闷，也写不肯沉沦的自信，是理解李白浪漫人格与盛唐精神的重要作品。

**主要意象:**
- 美酒珍馐：反衬内心郁结，显示外在丰盛与精神困境的落差
- 冰塞黄河、雪满太行：把人生阻隔具体化为险峻山河
- 云帆沧海：象征重新出发和理想实现

**学习要点:**
- 把握情绪转折：苦闷、追问、昂扬希望层层推进
- 重点理解“长风破浪会有时”的自我激励意味
- 可与[[poem/唐诗/001-诗-将进酒]]比较李白面对失意时的不同表达
