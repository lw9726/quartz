# 013-诗-山行

**作者:** [[诗人/024-诗人-杜牧]]  
**朝代:** [[时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学常见

**原文:**
```
远上寒山石径斜，白云生处有人家。
停车坐爱枫林晚，霜叶红于二月花。
```

**核心概述:** 这首诗写秋山枫叶之美，反转了传统悲秋情绪，呈现明朗喜悦的审美。

**主要意象:**
- 寒山石径：引出深秋山景
- 白云人家：让山景有生活气息
- 霜叶：以红胜春花，写秋色热烈

**学习要点:**
- 理解“坐爱”是“因为喜爱”的意思
- 重点体会“霜叶红于二月花”的审美反转
- 可与[[唐诗/014-诗-清明]]比较杜牧绝句的画面感
