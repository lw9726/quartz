# 007-诗-赠汪伦

**作者:** [[poem/诗人/001-诗人-李白]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学常见

**原文:**
```
李白乘舟将欲行，忽闻岸上踏歌声。
桃花潭水深千尺，不及汪伦送我情。
```

**核心概述:** 这首送别诗用桃花潭水反衬友情深厚，语言浅近而情感真切。

**主要意象:**
- 舟行：提示离别场景
- 踏歌声：让送别变得热烈而有生活气息
- 桃花潭水：以空间深度比喻情谊深度

**学习要点:**
- 把握“不及”带来的比较和夸张效果
- 送别诗不一定悲伤，也可以明快真诚
- 可与[[poem/唐诗/015-诗-送元二使安西]]比较送别风格
