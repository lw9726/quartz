# 018-诗-九月九日忆山东兄弟

**作者:** [[poem/诗人/017-诗人-王维]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学常见

**原文:**
```
独在异乡为异客，每逢佳节倍思亲。
遥知兄弟登高处，遍插茱萸少一人。
```

**核心概述:** 这首诗以重阳节为背景，写人在异乡对亲人的加倍思念。

**主要意象:**
- 异乡异客：直接点出漂泊处境
- 佳节：强化团圆缺席带来的思念
- 登高茱萸：通过节俗想象家人场景

**学习要点:**
- 重点理解“每逢佳节倍思亲”的普遍情感
- 后两句从想自己转为想兄弟，情感更委婉
- 可与[[poem/唐诗/003-诗-静夜思]]比较思乡方式
