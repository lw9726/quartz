# 011-诗-月下独酌

**作者:** [[诗人/001-诗人-李白]]  
**朝代:** [[时空/001-朝代-唐朝]]  
**体裁:** 五言古诗  
**常见场景:** 初高中常见

**原文:**
```
花间一壶酒，独酌无相亲。
举杯邀明月，对影成三人。
月既不解饮，影徒随我身。
暂伴月将影，行乐须及春。
我歌月徘徊，我舞影零乱。
醒时同交欢，醉后各分散。
永结无情游，相期邈云汉。
```

**核心概述:** 这首诗把孤独写成与月、影相伴的奇幻想象，体现李白自我排遣和精神自由。

**主要意象:**
- 月：被诗人拟作可以相邀的朋友
- 影：孤独自我的另一重投射
- 花间酒：营造浪漫而孤清的场景

**学习要点:**
- 理解“三人”其实是孤独中的想象性陪伴
- 注意诗中由孤独转向旷达的情绪变化
- 可与[[唐诗/003-诗-静夜思]]比较月亮意象
