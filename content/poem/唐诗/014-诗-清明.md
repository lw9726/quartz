# 014-诗-清明

**作者:** [[poem/诗人/024-诗人-杜牧]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学常见

**原文:**
```
清明时节雨纷纷，路上行人欲断魂。
借问酒家何处有，牧童遥指杏花村。
```

**核心概述:** 这首诗写清明雨中行旅人的惆怅，又用牧童一指带出远处生活气息。

**主要意象:**
- 纷纷细雨：烘托节令和情绪
- 行人：连接节日、旅途与思亲
- 杏花村：给惆怅画面加入温暖去处

**学习要点:**
- 注意前两句写情绪，后两句用人物动作转出画面
- 理解节令诗如何把民俗、天气和情感结合
- 可与[[poem/唐诗/018-诗-九月九日忆山东兄弟]]比较节日思亲
