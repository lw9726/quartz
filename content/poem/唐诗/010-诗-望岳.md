# 010-诗-望岳

**作者:** [[poem/诗人/002-诗人-杜甫]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 五言古诗  
**常见场景:** 初中常见

**原文:**
```
岱宗夫如何？齐鲁青未了。
造化钟神秀，阴阳割昏晓。
荡胸生曾云，决眦入归鸟。
会当凌绝顶，一览众山小。
```

**核心概述:** 这首青年杜甫写泰山雄伟，也写自己的胸襟和抱负。

**主要意象:**
- 泰山：象征高峻境界
- 曾云与归鸟：表现登临时的开阔视野
- 凌绝顶：由写景转向人生志向

**学习要点:**
- 重点理解“会当凌绝顶，一览众山小”的志向表达
- 前六句铺垫山势，最后两句升华主题
- 可与[[poem/唐诗/005-诗-登鹳雀楼]]比较登高与进取
