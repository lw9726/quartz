# 006-诗-望庐山瀑布

**作者:** [[poem/诗人/001-诗人-李白]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 七言绝句  
**常见场景:** 小学常见

**原文:**
```
日照香炉生紫烟，遥看瀑布挂前川。
飞流直下三千尺，疑是银河落九天。
```

**核心概述:** 这首诗以夸张和想象写瀑布壮美，是李白浪漫主义山水诗的典型入门篇。

**主要意象:**
- 香炉峰紫烟：把山色写得神秘绚丽
- 瀑布挂前川：把水流定格成视觉画面
- 银河落九天：用天上银河强化瀑布气势

**学习要点:**
- 理解夸张不是失真，而是突出气势和感受
- 注意“挂”“落”等动词的画面感
- 可与[[poem/概念/001-概念-浪漫主义]]关联理解
