# 017-诗-春望

**作者:** [[poem/诗人/002-诗人-杜甫]]  
**朝代:** [[poem/时空/001-朝代-唐朝]]  
**体裁:** 五言律诗  
**常见场景:** 初中常见

**原文:**
```
国破山河在，城春草木深。
感时花溅泪，恨别鸟惊心。
烽火连三月，家书抵万金。
白头搔更短，浑欲不胜簪。
```

**核心概述:** 这首诗写安史之乱中的长安春景，把国家破败、家人离散和个人衰老压缩在一首律诗中。

**主要意象:**
- 国破山河：用宏大对比写战乱创伤
- 花鸟：本应美好，却因时局触发悲痛
- 家书：集中表现乱世亲情的珍贵

**学习要点:**
- 理解“感时”“恨别”是全诗情感核心
- 注意个人白发与国家破败之间的互相映照
- 可与[[poem/诗人/002-诗人-杜甫]]联系理解“诗史”特征
