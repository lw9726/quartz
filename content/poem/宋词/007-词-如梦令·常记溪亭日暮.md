# 007-词-如梦令·常记溪亭日暮

**作者:** [[poem/诗人/030-诗人-李清照]]  
**朝代:** [[poem/时空/006-朝代-北宋]]  
**体裁:** 词，如梦令  
**常见场景:** 小学至初中常见

**原文:**
```
常记溪亭日暮，沉醉不知归路。
兴尽晚回舟，误入藕花深处。
争渡，争渡，惊起一滩鸥鹭。
```

**核心概述:** 这首词回忆少女时期游赏归舟的活泼场景，明快自然。

**主要意象:**
- 溪亭日暮：营造轻松游赏氛围
- 藕花深处：使画面清新明丽
- 鸥鹭惊起：让静态画面突然活跃

**学习要点:**
- 注意“争渡，争渡”的口语感和节奏感
- 理解这首词的清新活泼，不同于李清照后期愁词
- 可与[[poem/宋词/006-词-声声慢·寻寻觅觅]]比较风格变化
