# 009-词-浣溪沙·一曲新词酒一杯

**作者:** [[诗人/031-诗人-晏殊]]  
**朝代:** [[时空/006-朝代-北宋]]  
**体裁:** 词，浣溪沙  
**常见场景:** 初中常见

**原文:**
```
一曲新词酒一杯，去年天气旧亭台。
夕阳西下几时回？

无可奈何花落去，似曾相识燕归来。
小园香径独徘徊。
```

**核心概述:** 这首词写春日小园中的时间感，含蓄表达对流年消逝的惆怅。

**主要意象:**
- 新词酒杯：日常宴饮中的时间重复
- 落花归燕：一去一来，构成流逝与循环
- 小园香径：收束为独自徘徊的身影

**学习要点:**
- 重点理解“无可奈何花落去，似曾相识燕归来”的对偶与哲理
- 词的情绪温雅含蓄，不激烈却余味长
- 可与[[宋词/002-词-水调歌头·明月几时有]]比较时间哲思
