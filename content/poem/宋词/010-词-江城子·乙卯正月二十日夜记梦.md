# 010-词-江城子·乙卯正月二十日夜记梦

**作者:** [[诗人/003-诗人-苏轼]]  
**朝代:** [[时空/006-朝代-北宋]]  
**体裁:** 词，江城子  
**常见场景:** 高中常见

**原文:**
```
十年生死两茫茫，不思量，自难忘。
千里孤坟，无处话凄凉。
纵使相逢应不识，尘满面，鬓如霜。

夜来幽梦忽还乡，小轩窗，正梳妆。
相顾无言，惟有泪千行。
料得年年肠断处，明月夜，短松冈。
```

**核心概述:** 这首悼亡词以梦境重逢写生死阻隔，沉痛而克制，是苏轼深情婉约的一面。

**主要意象:**
- 孤坟与千里：表现生死和空间双重隔绝
- 小轩窗梳妆：以日常细节写梦中重逢
- 明月短松冈：把哀思固定为长期记忆

**学习要点:**
- 理解“不思量，自难忘”的克制表达
- 梦境让重逢发生，也让醒后的失去更沉痛
- 可与[[宋词/003-词-定风波·莫听穿林打叶声]]比较苏轼不同情感面向
