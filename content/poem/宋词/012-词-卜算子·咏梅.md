# 012-词-卜算子·咏梅

**作者:** 陆游  
**朝代:** 南宋  
**体裁:** 词，卜算子  
**常见场景:** 初中常见

**原文:**
```
驿外断桥边，寂寞开无主。
已是黄昏独自愁，更着风和雨。

无意苦争春，一任群芳妒。
零落成泥碾作尘，只有香如故。
```

**核心概述:** 这首咏梅词借梅花自况，写孤高坚守和不与世俗争艳的品格。

**主要意象:**
- 驿外断桥：孤独边缘的位置
- 风雨黄昏：压迫梅花的外部环境
- 香如故：象征人格不变

**学习要点:**
- 理解咏物诗词常常“托物言志”
- 重点体会“零落成泥碾作尘，只有香如故”的人格象征
- 可与[[主题/001-主题-个性解放]]联系理解独立精神
