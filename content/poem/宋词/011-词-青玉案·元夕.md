# 011-词-青玉案·元夕

**作者:** 辛弃疾  
**朝代:** 南宋  
**体裁:** 词，青玉案  
**常见场景:** 初高中常见

**原文:**
```
东风夜放花千树，更吹落、星如雨。
宝马雕车香满路。
凤箫声动，玉壶光转，一夜鱼龙舞。

蛾儿雪柳黄金缕，笑语盈盈暗香去。
众里寻他千百度。
蓦然回首，那人却在，灯火阑珊处。
```

**核心概述:** 这首词写元宵繁华中的寻觅，结尾以“灯火阑珊处”形成精神性的发现。

**主要意象:**
- 花千树、星如雨：写灯火盛景
- 鱼龙舞：写节日热闹流动
- 灯火阑珊处：从喧闹转向孤高与发现

**学习要点:**
- 把握上片繁华与下片寻人的结构反差
- “那人”可理解为真实人物，也可理解为理想人格
- 可与[[宋词/005-词-破阵子·为陈同甫赋壮词以寄]]比较辛弃疾的不同风格
