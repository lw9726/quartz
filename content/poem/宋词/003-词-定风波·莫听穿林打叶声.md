# 003-词-定风波·莫听穿林打叶声

**作者:** [[诗人/003-诗人-苏轼]]  
**朝代:** 北宋  
**体裁:** 词，定风波  
**常见场景:** 初高中常见

**原文:**
```
莫听穿林打叶声，何妨吟啸且徐行。
竹杖芒鞋轻胜马，谁怕？一蓑烟雨任平生。

料峭春风吹酒醒，微冷，山头斜照却相迎。
回首向来萧瑟处，归去，也无风雨也无晴。
```

**核心概述:** 这首词借途中遇雨写人生风雨，表现苏轼面对逆境时的从容和超脱。

**主要意象:**
- 穿林打叶声：外在风雨和人生扰动
- 竹杖芒鞋：朴素行走中的精神轻快
- 也无风雨也无晴：超越顺逆分别的境界

**学习要点:**
- 理解自然风雨与人生风雨的双关
- 重点体会“一蓑烟雨任平生”的人格态度
- 可与[[诗人/003-诗人-苏轼]]联系理解东坡式旷达
