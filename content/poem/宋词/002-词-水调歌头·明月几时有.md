# 002-词-水调歌头·明月几时有

**作者:** [[诗人/003-诗人-苏轼]]  
**朝代:** 北宋  
**体裁:** 词，水调歌头  
**常见场景:** 初中常见

**原文:**
```
明月几时有，把酒问青天。不知天上宫阙，今夕是何年。
我欲乘风归去，又恐琼楼玉宇，高处不胜寒。
起舞弄清影，何似在人间。

转朱阁，低绮户，照无眠。
不应有恨，何事长向别时圆？
人有悲欢离合，月有阴晴圆缺，此事古难全。
但愿人长久，千里共婵娟。
```

**核心概述:** 这首词由中秋望月写到人生离合，把个人思念提升为普遍的旷达祝愿。

**主要意象:**
- 明月：连接天上、人间与远方亲人
- 琼楼玉宇：表达超脱现实的想象
- 阴晴圆缺：把自然规律转化为人生哲理

**学习要点:**
- 重点理解“但愿人长久，千里共婵娟”的祝愿意味
- 词中既有思念，也有自我开解
- 可与[[宋词/001-词-念奴娇·赤壁怀古]]比较苏轼的旷达
