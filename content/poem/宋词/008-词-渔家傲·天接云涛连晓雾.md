# 008-词-渔家傲·天接云涛连晓雾

**作者:** [[poem/诗人/030-诗人-李清照]]  
**朝代:** [[poem/时空/025-朝代-南宋]]  
**体裁:** 词，渔家傲  
**常见场景:** 初高中常见

**原文:**
```
天接云涛连晓雾，星河欲转千帆舞。
仿佛梦魂归帝所。闻天语，殷勤问我归何处。

我报路长嗟日暮，学诗谩有惊人句。
九万里风鹏正举。风休住，蓬舟吹取三山去！
```

**核心概述:** 这首词以梦境写人生漂泊和精神突围，展现李清照少见的开阔豪迈。

**主要意象:**
- 云涛星河：打开宏阔梦境
- 帝所天语：带有神话色彩
- 风鹏与蓬舟：象征远举和超越

**学习要点:**
- 注意这首词不同于传统婉约的宏大想象
- 理解“路长嗟日暮”中的人生迟暮感
- 可与[[poem/概念/001-概念-浪漫主义]]比较想象方式
