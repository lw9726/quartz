# 006-词-声声慢·寻寻觅觅

**作者:** [[诗人/030-诗人-李清照]]  
**朝代:** [[时空/025-朝代-南宋]]  
**体裁:** 词，声声慢  
**常见场景:** 高中常见

**原文:**
```
寻寻觅觅，冷冷清清，凄凄惨惨戚戚。
乍暖还寒时候，最难将息。
三杯两盏淡酒，怎敌他、晚来风急！
雁过也，正伤心，却是旧时相识。

满地黄花堆积，憔悴损，如今有谁堪摘？
守着窗儿，独自怎生得黑！
梧桐更兼细雨，到黄昏、点点滴滴。
这次第，怎一个愁字了得！
```

**核心概述:** 这首词层层铺写孤独、漂泊和家国变乱后的愁绪，是婉约词后期沉郁化的代表。

**主要意象:**
- 叠字开篇：直接制造凄清节奏
- 淡酒、晚风、过雁：共同烘托孤独
- 梧桐细雨：把愁绪延长到黄昏

**学习要点:**
- 体会叠字在声音和情绪上的效果
- 理解“愁”不是单一情绪，而是个人遭遇与时代漂泊的叠加
- 可与[[宋词/007-词-如梦令·常记溪亭日暮]]比较李清照前后期风格
