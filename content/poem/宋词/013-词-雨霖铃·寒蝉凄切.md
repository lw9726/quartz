# 013-词-雨霖铃·寒蝉凄切

**作者:** 柳永  
**朝代:** 北宋  
**体裁:** 词，雨霖铃  
**常见场景:** 高中常见

**原文:**
```
寒蝉凄切，对长亭晚，骤雨初歇。
都门帐饮无绪，留恋处，兰舟催发。
执手相看泪眼，竟无语凝噎。
念去去，千里烟波，暮霭沉沉楚天阔。

多情自古伤离别，更那堪，冷落清秋节！
今宵酒醒何处？杨柳岸，晓风残月。
此去经年，应是良辰好景虚设。
便纵有千种风情，更与何人说？
```

**核心概述:** 这首词铺写离别全过程，把眼前送别和未来孤独连成一体，是婉约词写别情的代表。

**主要意象:**
- 寒蝉、长亭、骤雨：构成离别的凄清环境
- 兰舟催发：把情感停留和现实出发对立起来
- 杨柳岸、晓风残月：想象别后醒来的孤独场景

**学习要点:**
- 注意上片写临别现场，下片推想别后情境
- 理解“今宵酒醒何处”为什么成为千古名句
- 可与[[唐诗/015-诗-送元二使安西]]比较诗与词的送别写法
