# 004-词-永遇乐·京口北固亭怀古

**作者:** [[poem/诗人/012-诗人-辛弃疾]]  
**朝代:** [[poem/时空/025-朝代-南宋]]  
**体裁:** 词，永遇乐  
**常见场景:** 高中常见

**原文:**
```
千古江山，英雄无觅，孙仲谋处。
舞榭歌台，风流总被，雨打风吹去。
斜阳草树，寻常巷陌，人道寄奴曾住。
想当年，金戈铁马，气吞万里如虎。

元嘉草草，封狼居胥，赢得仓皇北顾。
四十三年，望中犹记，烽火扬州路。
可堪回首，佛狸祠下，一片神鸦社鼓。
凭谁问，廉颇老矣，尚能饭否？
```

**核心概述:** 这首词借京口怀古表达恢复中原的理想和报国无门的悲愤，是豪放词与历史典故结合的代表。

**历史人物与典故:**
- [[poem/历史人物/004-人物-孙权|孙仲谋]]：京口英雄记忆的开篇形象
- [[poem/历史人物/005-人物-刘裕|寄奴]]：金戈铁马、北伐功业的象征
- [[poem/历史人物/006-人物-刘义隆|元嘉]]：草率北伐失败的历史警示
- [[poem/历史人物/007-人物-霍去病|封狼居胥]]：军事功业的高度象征
- [[poem/历史人物/008-人物-拓跋焘|佛狸]]：敌方历史遗迹带出的沦陷感
- [[poem/历史人物/009-人物-廉颇|廉颇]]：词人自况和壮志未酬的核心典故

**主要意象:**
- 千古江山：展开历史纵深
- 金戈铁马：召回英雄气象
- 廉颇老矣：寄托词人自况和未尽之志

**学习要点:**
- 理解大量典故服务于现实政治关怀
- 重点把握怀古不是复古，而是借古论今
- 可与[[poem/概念/006-概念-豪放派]]关联
